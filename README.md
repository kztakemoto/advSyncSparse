
# advSyncSparse

This repository contains code for the research paper "Sparse adversarial control of synchronization in oscillator networks."

## Terms of Use
This project is licensed under the MIT License. 

## Requirements
* Python 3.11

Install the required dependencies:
```
pip install -r requirements.txt
```

## Usage
### 1. Data generation
```
cd data_gen
```

Note: The files generated by the commands below are also available for download from [Dropbox](https://www.dropbox.com/scl/fo/qqjweyj401l5jn7vu56fa/ACCHXg66T86EfJMxy0fJFpg?rlkey=ip5n9u2o9wmnqtungf2q2a37u&st=lil6p75y&dl=0).
If you'd rather skip data generation, you can download them, place them directly under `data_gen/`, and proceed to Section 2 (Figure generation).

#### All-to-all cost-performance
```
python gen_costperf.py --network a2a --N 1000 --eps 0.05
python gen_costperf.py --network a2a --N 1000 --eps -0.05
```

#### Kramers
```
python gen_kramers.py \
  --eps -0.03 -0.05 -0.07 \
  --K_ratios 3.0 \
  --deltas 0 0.3 0.5 0.6 0.7 0.8 0.9
```

#### ER cost-performance
```
python gen_costperf.py --network er --N 1000 --eps 0.05
python gen_costperf.py --network er --N 1000 --eps -0.05

```

#### BA cost-performance
```
python gen_costperf.py --network ba --N 1000 --eps 0.05
python gen_costperf.py --network ba --N 1000 --eps -0.05
```

#### Random-static annealed theory vs simulation
```
python run_random_theory.py
```

#### Strategy
For model networks
```
# ER
python gen_strategy_model.py --network er --eps 0.05
python gen_strategy_model.py --network er --eps -0.05

# BA
python gen_strategy_model.py --network ba --eps 0.05
python gen_strategy_model.py --network ba --eps -0.05
```

For emprical networks
```
python gen_strategy_real.py --eps 0.05
python gen_strategy_real.py --eps -0.05
```

### 2. Figure generation
```
cd figures
```

#### All-to-all cost-performance
```
python fig_costperf_signed.py \
  --pos ../data_gen/a2a_costperf_eps0.050_tau0.30_N1000.pkl \
  --neg ../data_gen/a2a_costperf_eps-0.050_tau0.30_N1000.pkl \
  --cp-K-pos 0.7 0.9 --cp-K-neg 1.2 2.0
```

#### Kramers
```
python fig_kramers.py ../data_gen/kramers_eps-0.070--0.050--0.030_tau0.30_K3.0_d0-0.3-0.5-0.6-0.7-0.8-0.9.pkl
```

#### ER and BA cost-performance
```
python fig_costperf_signed.py \
  --pos ../data_gen/er_costperf_eps0.050_tau0.30_N1000_deg12.pkl \
        ../data_gen/ba_costperf_eps0.050_tau0.30_N1000_deg12.pkl \
  --neg ../data_gen/er_costperf_eps-0.050_tau0.30_N1000_deg12.pkl \
        ../data_gen/ba_costperf_eps-0.050_tau0.30_N1000_deg12.pkl \
  --cp-K-pos 0.9 --cp-K-neg 2.0
```

#### Selection rules at a fixed budget
```
python fig_selection.py
```

#### Random-static annealed theory vs simulation
```
python fig_random_theory.py
```

#### Strategy
For ER and BA networks
```
python fig_strategy_model.py \ 
  ../data_gen/strategy_er_eps+0.050_tau0.30_N1000_deg12.pkl \
  ../data_gen/strategy_er_eps-0.050_tau0.30_N1000_deg12.pkl \
  ../data_gen/strategy_ba_eps+0.050_tau0.30_N1000_deg12.pkl \
  ../data_gen/strategy_ba_eps-0.050_tau0.30_N1000_deg12.pkl \
  --p 0.3
```

For emprical networks
```
python fig_strategy_real.py \
  ../data_gen/strategy_real_eps+0.050_tau0.30.pkl \
  ../data_gen/strategy_real_eps-0.050_tau0.30.pkl \
  --p 0.3 --combine 
```
